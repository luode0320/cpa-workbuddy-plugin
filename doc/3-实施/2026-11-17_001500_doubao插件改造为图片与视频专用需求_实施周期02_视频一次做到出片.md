# 实施周期 02：视频一次做到出片

结论：在周期 01 的纯技能管线上打通视频两段式——首轮返回参数确认与续接点，调用方二次确认后由插件经 `/im/chain/single` 轮询取回 `download_url`；影响：所有调 `doubao/video` 的调用方；范围：视频产物结构体与提取、会话续接点、确认轮形态、产物轮询、非流式与流式两条出口；非范围：不做插件内自动确认、不做多清晰度选择、不去水印、不改图片链路；变化：`doubao/video` 从「只回参数确认文本」变为真能返回可下载视频地址，且额度只由调用方的第二次请求触发；完成标准：生产 `/v1/chat/completions` 两轮后 `media[0].type=="video"` 且 URL 可下载；术语说明：确认轮指 `need_create_conversation=false` 的续接请求，续接点指 `conversation_id` / `last_section_id` / `last_message_index` 三元组；验证状态：需求侧已完成真实抓包取证，代码侧尚未改动。
