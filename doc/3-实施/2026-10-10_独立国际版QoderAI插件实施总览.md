# 独立国际版 Qoder AI 插件实施总览

结论：将国际版 Qoder（qoder.com / openapi.qoder.sh）从原国内版单插件体系中完全解耦，新建独立的 qoder-ai-provider 插件（目录 qoder-ai/），在 CPA 宿主中提供原生的国际站 OAuth 设备授权入口、PAT 导入、每日签到（100 积分）、专属的管理控制台（panel.html）以及与既有体系完全一致的低积分调度、故障退避、指定模型测试弹窗与跨插件 Token 用量监控。影响：彻底解耦国内版（QoderWork CN）与国际版（Qoder AI Global），CPA 宿主可直接提供原生 Qoder AI 登录与面板，免去在单插件内做繁琐的区域特判，底层保号分析、自动测试、自动切换与用量统计 100% 保持通用。范围：创建 qoder-ai/ 全套插件实现、专属管理面板、确定性单元测试、更新 token-usage-tracker 归一化展示、更新 CI 与本地构建支持。非范围：不修改 CPA 宿主核心二进制、不影响已上线的国内版 qoderwork-provider。完成标准：cgo-shim-build.py qoder-ai 构建/vet/测试全通过、双向哨兵拦截证明真实进编译、token-usage-tracker 单元测试通过、registry.json 与 build.yml 校验通过。

## 当前计划最终方案简要说明

以国内版成熟的 qoderwork-provider 与独立国际版 workbuddy-ai-provider 为蓝本，创建独立的 qoder-ai/ 插件工程。插件 ID 为 qoder-ai-provider，名称为 Qoder AI。所有上游端点纯化为 https://openapi.qoder.sh，原生 OAuth 登录（handleStartLogin）直连国际站授权端点 https://qoder.com/device/selectAccounts。完整支持专属于国际站的每日签到（每次 100 积分）与 4 小时后台定时巡检；管理面板定制为专属国际站控制台；用量数据写入共享 NDJSON 并由 token-usage-tracker 统一聚合展示。

## 基本信息与理解

### agent 理解的问题与目标
原 qoderwork-provider 单插件面向国内站（qoder.com.cn / openapi.qoder.com.cn / gateway.qoder.com.cn），用户提出 Qoder 同样存在国际版（qoder.com），并具备每日签到给 100 积分的功能。参考 workbuddy-ai-provider 的成功解耦经验，建立独立的 Qoder AI 国际版插件是最佳架构选择。这样宿主原生即可提供「Qoder AI」登录与面板，拥有独立的侧边栏面板菜单，所有路由、冷却、测试和用量功能完全与既有规范对齐。

### 本轮计划范围与非范围
- 范围：
  1. 独立插件源码：创建 qoder-ai/ 目录，实现 C ABI 导出、配置管理、OAuth 原生登录（https://qoder.com/device/selectAccounts）、PAT 导入、执行器转发、低积分路由调度器、定时活跃 ping 测试与指定模型弹窗测试、故障转移与 40x 重试、每日签到（+100 积分）系统与后台定时调度、生命周期软禁用（不物理删号）；
  2. 专属面板：定制 qoder-ai/panel.html 与 panel.go，路由前缀为 /v0/management/plugins/qoder-ai-provider，菜单展示为 Qoder AI，突出国际版每日签到、自动签到开关、批量签到与积分监控；
  3. 用量管道打通：在 qoder-ai/usage_feed.go 将 Provider 标为 Qoder AI，在 token-usage-tracker/usage_stats/auth_identity.go 增加对 qoder-ai / qoder-ai-provider 的友好名称归一化；
  4. 自动化测试：编写 qoder-ai/*_test.go，覆盖元数据契约、国际版端点、签到 100 积分响应解析、调度器与活跃探测，并完成双向哨兵拦截验证；
  5. 构建与流水线：验证 cgo-shim-build.py qoder-ai 全绿，更新 .github/workflows/build.yml 与 registry.json 元数据。
- 非范围：
  1. 跨项目写入红线：不修改父目录 CPA 宿主代码；
  2. 不影响国内版 qoderwork-provider 及其他插件的正常运行；
  3. 当轮未获显式提交/发布指令，不执行 git commit / git push。

### 关键假设与冻结约定
1. 插件 ID：qoder-ai-provider，展示名：Qoder AI，ProviderName 契约：qoder-ai-provider；
2. 凭证文件命名规范：qoderai-<uid>.json，凭证顶层 type: "qoder-ai-provider"，单账号兜底 qoderai.json；
3. 国际站端点基地址统一为 https://openapi.qoder.sh，推理接口与业务接口同网关；
4. 国际站每日签到给 100 积分（claim 返回 rewardCredits: 100）；
5. 调度器、冷却、retry_on_4xx、test_failed、active_ping 逻辑与最新规范同构。
