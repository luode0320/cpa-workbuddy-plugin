# ZCode Provider 插件移植与能力对齐实施总览

结论：把开源 `cpa-plugin-zcode` 插件移植并深度重构接入本项目，作为独立插件 `zcode-provider`（目录 `zcode/`），功能全方位对齐 `workbuddy` 企业级插件能力（多账号管理、专属控制台面板、选模型测试探活、会话/轮询调度与故障转移、流式推理转发、ZCode 桌面客户端真实指纹注入、用量统计上报及 CI 构建接入）；影响：CPA 宿主新增第 8 个模型供应商 `zcode-provider`，支持 BigModel Coding Plan 的 Anthropic 协议接入，用户可在面板中便捷导入管理多个 API Key 并进行可视化运维；范围：新建 `zcode/` 源码目录、管理接口与面板、调度与故障转移、流式执行器与指纹模拟、单元测试与反证哨兵、本地构建脚本与持续集成配置；非范围：不修改宿主核心二进制，不破坏既有兄弟插件现有逻辑；完成标准：本地 `python scripts/cgo-shim-build.py zcode` 编译、静态检查与单元测试全绿，反证哨兵证实真实进编译，面板脚本语法检查通过；验证状态：全部代码实现、本地构建测试、哨兵反证及 6-review 风格审查均已通过。

## 当前计划最终方案简要说明

以 `cpa-plugin-zcode` 的 ZCode 客户端指纹模拟（`mimic`）与 BigModel Anthropic 协议为基础，融合 `workbuddy` / `cursor` 成熟的多账号管理体系与专属面板交互：
1. 插件标识统一为 `zcode-provider`，版本初始为 `0.1.0`，落盘目录为 `zcode/`；
2. 账号物理凭据文件保存在 `~/.antigravity_cockpit/zcode_accounts/`，前缀 `zcode-<hash8>.json`；
3. 暴露完整的管理接口（`/accounts`, `/import`, `/export`, `/delete`, `/enable`, `/disable`, `/enable-all`, `/disable-all`, `/models?auth_index=`, `/test-active`）；
4. 提供开箱即用的 Web 管理控制台 `panel.html`，支持深浅主题切换、账号卡片、批量导入、导出、启停、删除及弹出选模型测试探活；
5. 推理执行器实现 `MethodExecutorExecute` 与 `MethodExecutorExecuteStream`，注入 ZCode 完整 Headers 指纹，将上游 SSE 流通过 `host.stream.emit` 逐块推送给宿主，支持 40x 换号与故障退避，并上报 Token 用量。

## Agent 对当前问题的理解

- 问题 / 目标：参考外部 `cpa-plugin-zcode` 仓库，在本项目中构建全新的 `zcode-provider` 插件，将其能力从基础单 Key 骨架大幅扩展对齐到 `workbuddy` / `cursor` 的多账号管理、面板运维、探活测试、故障转移和用量跟踪标准。
- 本轮范围：
  1. 创建 `zcode/` 目录结构；
  2. 实现 ZCode 指纹模拟（`internal/mimic`），保持精确请求头；
  3. 实现账号凭据管理与直写存储（`authfile.go`, `management.go`）；
  4. 实现 Web 管理面板（`panel.html`, `panel.go`）；
  5. 实现动态模型发现与映射（`models.go`）；
  6. 实现调度器与故障转移（`scheduler.go`, `failover.go`）；
  7. 实现推理执行器与流式转发（`executor.go`, `stream.go`）；
  8. 实现测试探活接口（`active_ping.go`）；
  9. 实现用量数据上报（`usage_feed.go`）；
  10. 编写单元测试及反证哨兵，确保 `cgo-shim-build.py zcode` 全绿；
  11. 接入 `scripts/cgo-shim-build.py` 与 `.github/workflows/build.yml` CI 矩阵。
- 非范围：不修改宿主核心二进制；不修改其他已有插件；暂不提交无 artifacts 的 `registry.json`（避免破坏自定义源原子校验）。
- 当前优先闭环：全套代码落地与本地编译测试验证全绿。
- 关键假设 / 待确认点：上游 BaseURL 默认为 `https://open.bigmodel.cn/api/anthropic`，支持配置覆盖；API Key 格式为 BigModel Key。

## 系统边界与现状基线

```text
zcode/
├── main.go                     # C ABI 导出、生命周期与宿主方法分发

├── models.go                   # 动态模型拉取、缓存与兜底列表
├── active_ping.go              # /models 查询与 /test-active 选模型探活测试
├── scheduler.go                # 多账号轮询调度、可用性筛选、test_failed 排除
├── failover.go                 # 429/5xx 阶梯退避冷却、40x 换号重试
├── executor.go                 # 非流式执行与 Anthropic 协议转换
├── stream.go                   # 流式执行、SSE 解析与 host.stream.emit 逐块推送
├── usage_feed.go               # Token 用量写入 token-usage-feed.ndjson
├── internal/mimic/
│   └── fingerprint.go          # ZCode 桌面客户端指纹计算与 Header 注入
└── *_test.go                   # 核心逻辑单元测试与必失败反证哨兵
.github/workflows/build.yml      # CI 矩阵接入 zcode
```
