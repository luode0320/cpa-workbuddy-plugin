# Trae 0.1.31 FIX-D 本地回归：pump gate reasoning 双轴健康度

## 目标

验证思考型长推理在 reasoning 阶段即流式放行（`pumpTraeStreamAttempt` gate 纳入 reasoning 双轴健康度），同时伪完成保护不回归。对应生产缺陷：`stream_id=2878` 深度思考请求 reasoning 阶段零字节 → nginx `proxy_read_timeout 300s` 504。

## 触发根因（生产取证摘要）

- 2026-09-02 CYCLE-04 生产验收，B2 形态（quickselect 深度算法 + 「深入思考后完整作答」prompt）触发 504。
- `stream_id=2878`：23:16:32 scheduled 后到 23:21:32 无任何插件 completion/error 日志，宿主 POST 5m0s 返回。
- 全程无 degrade/direct 日志 → 宿主桥 90s 读超时未触发 → 上游 reasoning 持续流入桥（桥健康）。
- 但 `pumpTraeStreamAttempt` gate 只累计 content（`contentChars += len(text)`），reasoning-only 分片被无限压 pending 不转发 → 插件→nginx→客户端方向 300s 无字节 → nginx `proxy_read_timeout 300s` 504。
- 对照：0.1.30 的 `isPseudoCompletion` 已豁免 reasoning 长流为健康（reasoning ≥600 不判伪），gate 却不放行 reasoning——判据与转发放行不一致。

## 代码改动

`traework/stream.go` `pumpTraeStreamAttempt`：
- `contentChars := 0` → `healthChars := 0`
- 累计 `healthChars += len(text) + len(reasoning)`（原 `contentChars += len(text)`）
- gate 打开条件 `healthChars < pseudoCompletionMaxChars`（双轴合计达 600 即放行）
- 函数头与第 1 步注释更新，说明双轴判据与不构成泄漏的理由

## 边界与残留

- 非范围：不判断 0.1.30 三缺陷（FIX-A/B/C）是否回归——该三缺陷测试集（executor_same_auth_retry_test.go 等）仍全绿，覆盖在 cgo-shim 全量中。
