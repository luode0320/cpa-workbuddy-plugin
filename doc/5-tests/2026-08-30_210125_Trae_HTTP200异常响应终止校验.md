# Trae HTTP 200 异常响应终止校验

结论：共享解析层已拒绝没有有效 `output` 和 `done` 的 HTTP 200 响应，避免返回空回答、空 stop 分片或错误成功记账。影响：同步非流式、同步流式和异步流式会把普通 JSON、HTML、未知事件、无换行尾帧及空 output 归为协议失败。范围：`traework/stream.go` 的三条响应出口。非范围：本轮不发起真实 Trae/Qwen 请求，也不修改账号切换预算、模型映射或上游网络配置。变化：增加统一终止状态并在三条出口验证后才成功结束。完成标准：模块 build、vet、既有测试和生产代码测试污染扫描通过；真实上游异常样本验证留待获得脱敏响应后执行。术语说明：有效终止是指上游产生可转换的 output 或显式发送 done。验证状态：本地代码级构建、静态检查和既有测试通过；真实上游响应验证受限。

## 验证结论

- 代码级验证：通过。共享状态 `traeSSETerminal` 仅在可转换的 output 或 done 出现后允许成功结束。
- 异常路径验证：仅静态验证。普通 JSON、HTML、未知事件、无换行尾帧、空 output 均会使终止状态无效并返回协议错误。
- 模块验证：通过。`cgo-shim-build.py traework` 的 build、vet、test 均成功。
- 生产代码测试污染：通过。扫描仅发现本轮修改的 `traework/stream.go`，输出 `POLLUTION: PASS`。
- 真实上游验证：受限。仓库没有可用的脱敏 Qwen 原始 SSE 样本，本轮不访问生产账号或发送真实请求。
- 浏览器联调：N/A。原因：本轮未修改页面或 HTTP 管理接口；证据：改动仅位于 SSE 响应转换逻辑。
- 图片资产决策：N/A。原因：验证对象为 Go 响应状态与错误分支；证据：没有需要通过位图表达的界面或视觉结果。

## 完成标准

1. 没有有效 output 和 done 的响应不会生成 completion 或 stop。
2. 异步流不会因无效响应调用成功复位或成功用量发布。
3. TraeWork 的 build、vet、test 与污染扫描均通过。
4. 获取脱敏上游样本后，使用真实输入确认协议错误出口。

## 本地授权与请求构造核验

- 验证环境：本机 Trae SOLO 的 `storage.json`。
- 验证方式：离线真实凭据读取与请求构造审查；未发送上游网络请求。
- 授权前置：通过。本机存在 `iCubeAuthInfo://icube.cloudide` 授权条目，且序列化值非空；未输出 credential、token、用户信息或其他敏感字段。
- 请求构造：通过。`parseTraeAuth` 可解析授权存储内容；`buildTraePayload` 将最小对话组织为 `llm_utils_chat` 请求体；`callLLM` 使用 `https://trae-api-cn.mchost.guru/api/agent/v3/llm_utils_chat` 和 Trae 授权头构造请求。
- 真实推理：未执行。本地测试隔离约束禁止自动调用外部 Trae 上游，因此本轮未验证授权是否被上游接受、`qwen3.8-max` 是否实际返回 output/done，不能宣称本地推理已通过。
- 人工验证交接：在用户可控的 Trae 客户端或已部署插件入口发送一条最小 `qwen3.8-max` 请求，核对 HTTP 状态、SSE 的 `output`/`done` 事件和客户端非空输出；日志或样本须移除 token、Cookie、Authorization 与私密消息。
