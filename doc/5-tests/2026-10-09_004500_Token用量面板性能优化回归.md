# Token 用量面板性能优化回归（SSE 移除与手动刷新）

结论：把 Token 用量面板的自动刷新链路（SSE 短连接轮询与 15 秒定时轮询）整体移除，改为仅在打开面板与点击「刷新」按钮时加载；默认时间范围改为「最近 1 小时」，减少打开面板时的数据量；同时修复插件图标（自有仓库托管新图标并更新注册元数据）；影响：打开 Token 用量面板不再持续消耗服务器性能，插件列表恢复图标展示；范围：token-usage-tracker 后端 SSE 通道、面板前端逻辑、时间范围模式与本地化、图标资产与 registry；非范围：不修改统计口径与聚合逻辑、不修改其它插件、不改动宿主核心；变化：面板打开从持续自动刷新变为单次加载加手动刷新，默认视图从今天变为最近 1 小时；完成标准：本地隔离构建全绿、面板回归脚本通过、图标与注册表校验通过；术语说明：SSE 是服务器向浏览器持续推送事件的短连接通知机制，本轮已整体移除；验证状态：真实测试与格式门禁均已通过。

## 文档信息

- 来源：用户反馈「Token 用量面板打开时非常消耗服务器性能」与「Token 用量插件没有图标」，要求去掉 SSE 刷新、改为手动触发刷新、默认只加载最近 1 小时数据，并修复插件图标。
- 实施记录：后端移除 `usage/events` 路由、事件处理函数与 feed 通知序列；前端删除 EventSource 与 15 秒定时器，新增 `last_1_hour` 预设并设为默认，四个语言包同步补充文案；图标以 `assets/icons/TokenTracker.png` 入库，插件 Logo 地址与注册表 logo 字段同步更新。
- 真实验证：`node test/token-usage/panel_perf_repro.mjs` 在 Node `vm` 与 DOM 桩中真实执行面板内联 JS，全部断言通过、退出码 0；`python scripts/cgo-shim-build.py token-usage-tracker` 完成 build、vet、test 全绿。
- 性能验证：本轮回归的直接目标即性能；断言以「启动后 EventSource 构造次数为 0」「setInterval 调用次数为 0」「默认加载窗口为 3600000 毫秒」量化验证。
- 图片资产决策：N/A + 原因 + 证据：本轮回归对象是面板脚本行为与图标像素校验，证据由脚本断言与像素校验覆盖，不需要图片资产。

## 验证策略

面板的 JS 通过 `//go:embed` 编进插件 `.so`，`node --check` 只能查语法、抓不到运行期的连接建立与定时器注册。因此本轮回归用 Node `vm` 建隔离上下文与 DOM 桩，把 `dashboard.go` 内联模板中的两个 `script` 块真实跑起来，再按真实启动链路驱动：

1. 启动阶段：模拟页面初始化完成之后的面板启动，断言不建立 EventSource、不注册 setInterval。
2. 首屏加载：断言默认范围为 `last_1_hour`，首屏请求的统计窗口约为 1 小时（3600000 毫秒）。
3. 手动刷新：点击刷新按钮后断言重新拉取一次 `stats/initial`，请求计数从 1 增加到 2。
4. 源码级清理：断言 `dashboard.go`、`management.go`、`feed_ingest.go` 中不再含 SSE 与定时器相关符号。
5. 反证：对改动前的 `dashboard.go` 快照运行 `--legacy` 模式，必须识别出旧版 EventSource、15 秒定时器与 `/usage/events` 地址，证明脚本能真实区分新旧行为。

## 改动文件

- `token-usage-tracker/management.go`：删除 `usage/events` 资源路由、`serveUsageEvents` 函数与 `statsReadAPIPath` 中的对应分支。
- `token-usage-tracker/feed_ingest.go`：删除 feed 通知序列（`feedNotifierMu`、`feedNotifierSeq` 与读写函数）。
- `token-usage-tracker/feed_ingest_test.go`：原 SSE 测试改为路由移除负向断言 `TestUsageEventsRouteRemoved`。
- `token-usage-tracker/usage_stats/dashboard.go`：删除 `startUsageEvents`、`startTimer` 与 `refreshTimer`，新增 `last_1_hour` 预设并设为默认。
- `token-usage-tracker/usage_stats/preferences.go`：默认时间范围改为 `last_1_hour` 并加入白名单。
- 四个语言包 `token-usage-tracker/usage_stats/locales/*.json`：新增 `range.lastHour` 文案。
- `assets/icons/TokenTracker.png`：新增 192×192 透明底图标。
- `token-usage-tracker/main.go`：插件 Logo 地址改为本仓库图标地址，版本号升至 0.2.4。
- `registry.json`：workbuddy-token-usage 条目补充 logo 字段。
- `test/token-usage/panel_perf_repro.mjs`：新增长期回归脚本，支持 `--legacy` 反证。
