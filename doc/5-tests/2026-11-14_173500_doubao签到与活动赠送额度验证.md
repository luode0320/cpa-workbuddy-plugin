## 3. 新增用例清单（13 个，`doubao/checkin_test.go`）

| 用例 | 锁定的行为 |
|---|---|
| `TestFetchCampaignDetailParsesDailySignin` | web 形态详情解析出 `daily_signin`，读到 `reward.reward_amount=200`；请求体含 `campaign_group_code` |
| `TestFetchCampaignDetailRejectsBusinessCode` | `code != 0` 时返回错误而非空详情，避免把失败当「未签到」 |
| `TestFetchLandingChosenType` | `chosen_type:0` → 0；`chosen_type:3` → 3 |
| `TestFetchQuotaGroupsReadsActivityGrant` | 从 `incentive_quota_section.window_limit_groups[0].window_limits[0]` 取到 `活动赠送额度` 与 200/200/100/`1797237901995`；锁死「分组名取同层」这一实现 |
| `TestRunCheckinSkipsDesktopChannel` | **红线**：`chosen_type=3` 时 stub 收到的路径**不含** `checkinRunPath`，state=`desktop_only` |
| `TestRunCheckinSubmitsWhenWebChannel` | `chosen_type=0` 且未签：调用顺序为 `detail → landing → checkin → detail`，最终 state=`done` |
| `TestRunCheckinReportsWhenUpstreamNotConfirmed` | 提交成功但回查仍 `checked_in_today=false`：state=`error`，文案含「未确认到账」 |
| `TestRunCheckinSkipsWhenAlreadySigned` | 首查已签：不产生任何写请求，state=`done` |
| `TestNextCheckinTimePicksNextSlot` | 09:00→当日 10:00；10:00→当日 22:00；23:30→次日 10:00 |
| `TestCheckinStateTextCoversAllStates` | 五个状态枚举都有中文文案，未知名回落「签到失败」 |
| `TestCheckinStatusForReportsQuota` | 只读探测同时给出 state 与 quota；额度失败走 `quota_error` 而不是整体失败 |
| `TestCampaignCodeHintCoversKeyCodes` | `2` / `710012001` / `710010702` 三个关键码各有可操作中文提示 |
| `TestNumberValueAcceptsBothShapes` | `200` / `"1,200"` / `"¥ 88.5"` / `null` → 200 / 1200 / 88.5 / 0 |
