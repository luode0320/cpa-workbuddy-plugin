## 3. 新增与修改用例清单

### 3.1 CYCLE01 — URL 可信（`doubao/creation_test.go`）

| 用例 | 锁定的行为 |
|---|---|
| `TestVideoStreamRank` | 5 案例：无 `lr`→Plain；`lr` 含 `unwatermark`（含大小写）→Clean；`lr` 为其他值→Watermarked；URL 解析失败→Plain |
| `TestBestStreamPrefersUnwatermark` | 1080p 带水印 vs 720p 无水印，必须选无水印（证明水印等级优先于清晰度） |
| `TestBestStreamSkipsExpiredURL` | `url_expire=1`（已过期）时 bestStream 返回空，不交出过期直链 |
| `TestBestStreamStableOnTie`（既有，未改） | 两流均无 `lr`→都 Plain，同分按 key 定序仍取 `a.mp4`，确定性契约未破 |

### 3.2 CYCLE02 — 失败快速换号

| 用例 | 文件 | 锁定的行为 |
|---|---|---|
| `TestUpstreamErrorClassification`（修改） | `doubao/completion_test.go` | 新增 `710022002` → `isRateLimit()==true`；既有 429/710022005/710012001/400/500 断言保持 |
| `TestAssetsFromChainResponseRejectsBusinessError`（修改） | `doubao/video_chain_test.go` | 改用 `asUpstreamError` 断言业务码 `10001` 返回 `*upstreamError` 且 `Code==10001`（不再是裸 `fmt.Errorf`） |
| `TestNextPollInterval`（新增） | `doubao/video_chain_test.go` | `0s/59s`→快轮询间隔；`60s/61s`→常规 10s；快间隔取 `min(fast, normal)`，测试压缩不被固定 5s 绕过 |
| `TestWaitVideoAssetEarlyExitOnRateLimit`（新增） | `doubao/video_chain_test.go` | httptest 回 `status_code=710022002`，`context.WithTimeout` 4s 保护；断言错误链含 `upstreamError{Code:710022002}`、耗时 `< videoFastPollInterval`、只拉取 1 次 |

### 3.3 CYCLE03 — 参数与产物判据

| 用例 | 文件 | 锁定的行为 |
|---|---|---|
| `TestNormalizeVideoParams`（既有，未改） | `doubao/request_test.go` | 上界用 `videoDurationMax` 符号（60→15 自动适配）；`16s` 回落缺省；缺省路径逐字节不变 |
| `TestCreationAssetPlayable`（修改） | `doubao/creation_test.go` | 成品样例补 `Status:3`；新增「状态未定稿」（Status=0 + URL 非空）→ false |

## 4. 哨兵反证（新增用例真实进编译 + 判据有效）

| CYCLE | 临时改动 | 期望失败 | 实测 |

| 02 | 早退条件改 `if false && errors.As(...)` | `TestWaitVideoAssetEarlyExitOnRateLimit` FAIL | `--- FAIL: TestWaitVideoAssetEarlyExitOnRateLimit (4.00s)`；恢复后全绿 |
