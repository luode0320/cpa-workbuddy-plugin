## 3. 变异与反证

- **令牌不经 query 传递**：`buildBookmarkletScript` / `buildAuthScript` 生成的跳转目标只拼 `#token=`，`TestBuildBookmarkletScriptKeepOriginPlaceholder` 断言脚本里不含 `?token`；若改回 query，宿主访问日志会记录令牌，该断言随之失败。
- **token beat 端点真的被调用**：`tokenBeatFixtureServer` 起 httptest 并断言收到 `sdk-version: 2` 与 `x-tt-token`，`swapTokenBeatEndpoint` 注入后兑换成功；把端点改回真实域名则测试直接失败（无网络 / 无凭据）。
- **回调失败一律 HTTP 200**：`TestHandleLoginCallbackReportsScriptError` 断言状态码 200 且 ok=false；改成 4xx 会让面板把「脚本取不到令牌」误判成管理密钥失效。
- **重放保护不是装饰**：`TestHandleLoginCallbackReplayIsIdempotent` 第一次兑换后清空夹具 Set-Cookie，第二次请求仍返回 ok=true「该授权已完成」；去掉 `loginImportedAuthID` 短路就会二次兑换失败。
- **固定书签能关掉宿主弹窗**：`TestHandleLoginCallbackLooseWithoutState` 先登记 pending 会话再走无 state 回调，断言返回「管理页会自动关闭」；去掉 `adoptPendingLoginSession` 会退化成「回到面板刷新」。
- **回环不得覆盖公网 origin**：`TestRememberPublicOriginPrefersForwardedHost` 先记 `cpa.uode.vip` 再发 `127.0.0.1:8317`，断言 origin 不变；去掉回环判断后宿主弹窗里的授权地址会变成内网地址。
- **新增测试真实进编译**：`go test -v` 输出里 `tokenbeat_test.go` 的 15 个 TestXxx 全部出现且 PASS，证明不是仅存在于磁盘。
