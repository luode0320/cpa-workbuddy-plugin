## 7 语言与框架特异写法（STYLE-08）

1. **不读未加锁字段**：`restartKeepalive` 只在 `keepaliveMu` 保护下读写 `keepaliveCancel` / `keepaliveDone`；`stopKeepalive` 先加锁取走再解锁等待，避免持锁阻塞 `configurePlugin`。
2. **`select` 双分支处理退出**：`for { select { case <-ctx.Done(): return; case <-ticker.C: runKeepaliveOnce(ctx) } }`，与 `video_chain.go` 的 `select { case <-ctx.Done(): … case <-time.After(videoPollInterval): }` 同形，不用 `time.Sleep` 轮询。
3. **`defer ticker.Stop()` 与 `defer close(done)` 顺序**：先 `defer close(done)` 再 `defer ticker.Stop()`，保证停止信号先发出。
4. **错误只记日志不返回**：`refreshMsTokenByProbe` 无返回值，所有失败路径 `log.Printf(...)` 后 `return`。理由写在文件头——保活失败不属于业务请求失败，写进 `noteAccountFailure` 会让一次网络抖动冷却好账号。
5. **`http.Header.Get` 大小写不敏感**：用 `resp.Header.Get(msTokenHeader)`（常量值 `"x-ms-token"`），Go 内部做 canonical 化，不需要手工处理 `X-Ms-Token` 变体。
6. **`io.Copy(io.Discard, io.LimitReader(...))` 读完丢弃**：不为保活解析 body，只为让连接可复用，与 `cookiejar.go` 的 `io.CopyN(io.Discard, resp.Body, 1<<12)` 手法一致。
7. **布尔配置用指针区分「未写」与「写了 false」**：`configOverride.KeepaliveEnabled *bool`。这是本轮唯一为语义正确性引入的间接层，注释写了完整理由。
8. **`sa.MsToken = token` 必须在 `jar.persist(sa)` 之前**：persist 序列化的是传入结构体，顺序错了写盘还是旧值。已用哨兵 `persist` 固化。
