导入 QoderWork 凭证

到 qoder.com.cn → 设置 → Personal Access Tokens 创建一个 PAT（pt- 开头）。单条粘贴到下方输入框；多条或已有备份文件请用下面的「批量导入」。插件会自动换取 jobToken 并保存为 qoderwork-<uid>.json。

PAT 长期有效（可在创建时设置过期时间）。插件存储 PAT 用于 jrt- 过期后自动续期，无需重新导入。

批量导入：可一次选择多个 JSON 文件，也可把混排内容粘贴到下方——PAT 列表（每行一个 pt-，一行内多个用逗号/空格分隔也认）、单个凭据、凭据数组、导出备份文件、JSONL（每行一个 JSON 对象）全部自动识别；PAT 走上游换 token，凭据直接离线回灌。
