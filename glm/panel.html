添加账号

授权方式（token）：打开 授权页，按页面指引从 chatglm.cn 复制 chatglm_refresh_token 粘贴提交即可。

或手工粘贴：在浏览器打开并登录 chatglm.cn → 按 F12 → Application → Local Storage → 找到 chatglm_refresh_token → 复制它的值。
